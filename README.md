# Research Abstract Classification

A three-class NLP classification project for **Science**, **Business**, and **Social Science** research abstracts. It follows the supplied assignment brief and compares Logistic Regression, Decision Tree, Naive Bayes, kNN, SVM, and Random Forest.

## Project structure

```text
abstract_classifier_project/
├── app.py
├── requirements.txt
├── README.md
├── data/
│   └── abstracts_labeled.csv
├── notebooks/
│   └── abstract_classification_exploration.ipynb
├── src/
│   ├── preprocessing.py
│   └── train.py
├── models/                 # generated by training
└── reports/                # generated by training
```

## Dataset and cleaning

The three supplied CSV exports are combined and labeled from their source file:
- `science.csv` → Science
- `socialScience.csv` → Social Science
- `business.csv` → Business

The modeling input is the `Abstract` column. Empty abstracts are excluded, exact duplicate abstracts are removed, and abstracts occurring under more than one source label are excluded to avoid contradictory training targets. The resulting labeled dataset is in `data/abstracts_labeled.csv`. Other bibliographic columns are retained for traceability but are not used as model features.

## Setup

Python 3.10+ is recommended.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

## Train and compare models

Run from the project root:

```bash
python src/train.py
```

This creates:
- `reports/model_comparison.csv` with accuracy, weighted precision, recall and F1
- one confusion-matrix PNG and classification report CSV per classifier
- `models/best_model.joblib` selected by weighted F1
- `models/model_info.json`

The split is stratified (80% train / 20% test, random state 42). The notebook contains exploratory analysis, preprocessing review, model comparison, and visualizations.

## Run Streamlit demo

After training:

```bash
streamlit run app.py
```

The landing page shows model metric comparisons, selectable confusion matrices, and sample counts by class. The prediction area supports:
1. A single abstract uploaded as a `.txt` file or pasted into the app.
2. Batch CSV prediction using a required `Abstract` column; results can be downloaded.

## Notes and limitations

- NLTK tokenization and stopword resources are fetched on first use if not already installed. The preprocessing fallback still runs if a resource download is unavailable.
- Negation terms (for example, “not” and “without”) are retained because they can alter abstract meaning.
- The best model is selected using weighted F1 on the held-out test set. For a formal final evaluation, use cross-validation on the training partition and preserve a final untouched test set.
- These are baseline models. Review errors and potential topic/source bias before interpreting predictions as definitive scholarly classifications.
